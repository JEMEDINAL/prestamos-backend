# 🚀 API Prueba Tecnica

API REST desarrollada con **Java 21** y **Spring Boot**, como parte de una prueba técnica.

## 🛠️ Tecnologías utilizadas

- Java 21
- Spring Boot
- Maven
- Spring Web
- Spring Data JPA
- Hibernate
- Base de datos: H2
- Spring Security
- Json web Token

## ✅ Requisitos previos

- **Java 21**
  ```bash
  java -version
  mvn -version ...

📥 Instalación del proyecto
  1. Clonar proyecto
   git clone https://github.com/JEMEDINAL/prestamos-backend.git
  2. Ingresar al proyecto:
    cd nombre-del-proyecto
  3. Compilar el proyecto:
    mvn clean install


▶️ Ejecución de la aplicación

Ejecutar con Maven:

mvn spring-boot:run

O ejecutar el JAR generado:

java -jar target/nombre-del-proyecto.jar
